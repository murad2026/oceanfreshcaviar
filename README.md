# Ocean Fresh Caviar

Сайт заказа икры с курьерской доставкой по Бостону.
Статичный: HTML + CSS + JS, без сборки и зависимостей.

**Домен:** www.oceanfreshcaviar.com · **Instagram:** [@oceanfreshcaviar](https://instagram.com/oceanfreshcaviar)

## Как это работает

Оплаты на сайте нет. Покупатель выбирает фасовки, заполняет форму — и заказ
уходит одним готовым сообщением в WhatsApp на номер из настроек. Дальше мы
связываемся с человеком, подтверждаем наличие и договариваемся об оплате и
доставке. Есть два сценария: **купить в наличии** и **бесплатный предзаказ**.

## Что менять — всё в одном файле

`assets/js/config.js`. Больше никуда лезть не нужно:

| Что | Где в файле |
|---|---|
| Телефон, Telegram, email, Instagram | `contacts` |
| Куда уходит заказ (`whatsapp` / `telegram` / `email`) | `primaryChannel` |
| Цены, фасовки, наличие | `products[].variants` |
| Название и описание икры | `products[].name`, `subtitle`, `description` |
| Зона, дни, срок доставки | `delivery` |
| Способы получения (самовывоз, курьер, отправка) | `shipping` |
| Дата окончания сбора, обратный отсчёт | `season` |
| Оплата картой (Stripe Payment Links) | `payments` |
| Остатки по фасовкам | `stock` внутри `variants` |

Пока `pricesArePlaceholder: true`, вверху сайта висит жёлтое предупреждение,
что цены временные. Поставили реальные цены — смените на `false`.

Наличие переключается флагом: `inStock: true` даёт кнопку «Купить»,
`inStock: false` — «Предзаказ бесплатно».

Остаток указывается полем `stock` в строке фасовки: `stock: 12` покажет
«осталось 12 банок», `stock: 0` — «закончилось» и переведёт строку в
предзаказ. Если поле не указано, остаток не показывается. Цифры имеет
смысл держать честными — это единственное, что покупатель не может
проверить, и единственное, за что бьют больнее всего.

## Оплата картой

Механика готова и выключена: `payments.enabled: false`. Чтобы включить:

1. В Stripe создать Payment Link на каждую фасовку (Products → нужный товар
   → Create payment link). В настройках ссылки включить сбор адреса доставки
   и поставить доставку $0 — внутри I-495 она бесплатна.
2. Скопировать ссылки в `payments.links` под ключом `товар-граммы`, например
   `"siberian-250": "https://buy.stripe.com/..."`. Ключ совпадает с `id`
   товара и числом граммов.
3. Поставить `payments.enabled: true`.

В блоке заказа появится кнопка «Оплатить картой». Она работает, когда в
заказе одна позиция со ссылкой; при нескольких позициях сайт предлагает
отправить заказ и получить ссылку на общую сумму от нас. За пределами
I-495 доставка считается по адресу, поэтому онлайн-оплата там не
предлагается — ссылку высылаем после расчёта.

Блок про сезон живёт в `season`: дата `harvestEnds` задаёт обратный отсчёт,
он пересчитывается сам при каждом открытии сайта. После этой даты вместо
счётчика появляется «Сбор завершён — продаём из заложенного запаса».

Второй вид икры добавляется копией блока внутри `products` — карточки
отрисуются сами.

Тексты сайта — в `assets/js/i18n.js` (русский и английский рядом).
Язык выбирается по языку браузера, переключатель в шапке.

## Публикация

Сайт публикуется на **GitHub Pages** напрямую из ветки `main`:
Settings → Pages → Source → **Deploy from a branch** → `main` → `/ (root)`.
Сборки нет — что лежит в репозитории, то и на сайте. Каждый push в `main`
обновляет сайт за минуту-две.

Домен `www.oceanfreshcaviar.com` задан в Settings → Pages → Custom domain и
продублирован файлом `CNAME` в корне. Файл `.nojekyll` отключает обработку
Jekyll — нужен, чтобы GitHub отдавал файлы как есть.

DNS у регистратора домена:

| Тип | Имя | Значение |
|---|---|---|
| CNAME | `www` | `murad2026.github.io` |
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |

Четыре A-записи нужны, чтобы `oceanfreshcaviar.com` без `www` тоже открывался
и редиректил на основной адрес. Обновление DNS занимает от нескольких минут
до пары часов.

## Страницы позиций

```bash
node tools/build-pages.js
```

Собирает `caviar/<id>.html` — по странице на каждую позицию каталога:
крупная банка, вкус и характеристики, фасовки с ценами, путь заказа до
двери и отзывы. Кнопка «+» на такой странице ведёт на главную и сразу
кладёт позицию в заказ. Запускать после добавления или переименования
товаров в конфиге.

## Фотографии

- `assets/img/<id>.jpg` — зерно крупным планом (круглый образец в карточке).
- `assets/img/tins/<id>.jpg` — банка (квадрат, крышка по центру).

Оба подхватываются сами, ничего в коде менять не нужно; нет файла —
показывается нарисованный образец зерна.

## Отзывы

Массив `reviews` в конфиге. Каждый отзыв: `product` (id позиции или
пропустить, чтобы показывать у всех), `photo`, `author`, `date` и `text`
на двух языках. Пустой массив — блок отзывов не показывается.

## Прайс-лист в PDF

```bash
node tools/build-pricelist.js
```

Собирает `pricelist/ocean-fresh-caviar-pricelist.pdf` — две страницы на
английском и две на русском — прямо из `assets/js/config.js`. Поменяли цены
на сайте, запустили команду — прайс совпадает с каталогом, расхождению
взяться неоткуда.

Скрипту нужен `playwright-core` и путь к Chromium: `npm i playwright-core`,
при необходимости `CHROME_PATH=/путь/к/chrome node tools/build-pricelist.js`.
