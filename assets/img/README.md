# Фотографии икры

Сюда кладутся снимки зерна — по одному на вид, именем совпадающим с `id`
товара из `assets/js/config.js`:

```
paddlefish.jpg      hackleback.jpg     kaluga.jpg
white-sturgeon.jpg  siberian.jpg       beluga-hybrid.jpg
velvet.jpg          chum.jpg           gold-chum.jpg
pink.jpg
```

Файл подхватывается сам: как только он появился, вместо нарисованного
образца в карточке и в таблице сравнения показывается фотография. Ничего
в коде менять не нужно. Если файла нет — остаётся рисованный образец.

**Требования к кадру.** Квадрат (обрезается в круг), икра занимает весь
кадр — без банок, ложек, тарелок и подписей по краям. Снимать сверху,
при дневном свете у окна, без вспышки. Достаточно 800×800 пикселей;
больше 1600×1600 нет смысла — только вес страницы.

**Права.** Ставьте только свои снимки или те, на которые у вас есть
разрешение. Кадрирование чужой фотографии не делает её своей, а чужой
бренд на банке в кадре — отдельная претензия.
