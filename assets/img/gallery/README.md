# Настоящие фото

Сюда — только собственные снимки. Смысл блока в том, что это снято нами:
студийные и стоковые кадры его обесценивают, для красивой икры уже есть
фотографии банок в `assets/img/tins/`.

Что работает лучше всего, по убыванию:

1. **Собранный заказ до закрытия коробки** — термокороб, гелевые пакеты, крафт.
   Единственное доказательство холодовой цепи, которое клиент может увидеть
   до покупки.
2. **Вскрытая банка с ложкой** — перламутровой или костяной, не металлической.
3. **Коробка на пороге у клиента** — если пришлёт сам.
4. **Подача на столе** — блины, тосты, лёд.

Требования к файлам:

- длинная сторона 1600 px, JPEG, до ~250 КБ;
- имя латиницей через дефис: `box-packed.jpg`, `tin-opened.jpg`;
- на кадре не должно быть чужих брендов и чужих этикеток, если это не
  сознательное решение — покупатель читает их как настоящего продавца.

После загрузки добавь запись в `gallery` в `assets/js/config.js`.
Пустой массив — блок на сайте не показывается.
