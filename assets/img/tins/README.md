# Банки

Макеты крышек — по одному файлу на позицию, имя совпадает с `id` товара
из `assets/js/config.js`:

```
paddlefish.jpg   hackleback.jpg   kaluga.jpg    white-sturgeon.jpg
siberian.jpg     beluga-hybrid.jpg  velvet.jpg
chum.jpg         gold-chum.jpg    pink.jpg
```

Файл подхватывается сам: появился — в карточке каталога и на странице
позиции вместо образца зерна показывается банка. Нет файла — остаётся
нарисованный образец.

Кадр: квадрат, крышка по центру, поля минимальные. 1200×1200 достаточно.
